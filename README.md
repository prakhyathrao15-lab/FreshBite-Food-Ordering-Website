# FreshBite-Food-Ordering-Website
A responsive food ordering website built using HTML and CSS as part of a virtual internship project.
FreshBite is a responsive front-end food ordering website developed using HTML, CSS, and JavaScript. The project provides a modern and user-friendly interface where customers can browse restaurants, explore food items, and experience a simple online ordering workflow.
# Features
-Responsive Homepage
-Restaurant listing page
-Food menu with categories
-Shopping cart page
-Checkout page
-Login and Account pages
-Contact and About Us pages
-Restaurant search functionality
-Add to Cart interaction
-Smooth navigation
-Hover animations and responsive design
# Technologies used
frontend technologies used were-
-HTML-structure
-Css-styling
-JavaScript-Intereactivity and functionality
